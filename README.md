# 「崩壊地抽出AIアプリ」と「色調整アプリ」
このリポジトリでは「崩壊地抽出AIアプリ」と「色調整アプリ」のPythonスクリプトとWindows用アプリ（EXEファイル）を提供しています。
これらのWindows用アプリはインストール不要で、画面でフォルダやファイルを選択できるようになっています。

なお、これらは、 内閣府の”研究開発とSociety5.0との橋渡しプログラム（BRIDGE）”において、令和6年度に採択された「迅速な災害復旧等に向けた時系列・三次元モデルを用いた国土履歴のAI判別技術の開発・普及」の「テーマ⑶　時系列デジタルツインを活用した情報抽出技術の開発・実証」の一環として開発しました。

## アプリのダウンロード
アプリとAIモデルファイル（カラー版とグレースケール版）は、[Release](https://github.com/KouichiAraki/LandslideDebrisFlowAreaDetection/releases/tag/v1.0.0)
からダウンロードできます。

## 崩壊地抽出AIアプリ
崩壊地抽出AI.exeをダブルクリックすることで画面が表示されます。
各項目を選択・入力して「実行」ボタンをクリックすると、AIによる抽出が開始されます。
「モデルファイル」は、入力となる分割画像がカラーであればAiModel_Color.h5を選択し、グレースケールであればAiModel_Gray.h5を選択してください。

![崩壊地抽出AIの画面](docs/崩壊地の裸地検出.png)

## 色調整アプリ
色調整.exeをダブルクリックすると画面が表示されます。
各項目を選択・入力して「実行」ボタンをクリックすると、グレースケールの分割画像に対して色調整が開始されます。
「閾値（整数）」はマスクするための閾値です。詳細は[1]を参照ください。

![色調整の画面](docs/色調整.png)
